Biến động nhân sự theo tháng

Tải lên 3 file xuất từ hệ thống (Hợp đồng, Quyết định thôi việc, Sự nghiệp), chọn tháng để xem ai ký hợp đồng, tăng lương, được bổ nhiệm và nghỉ việc. File chỉ được đọc trong trình duyệt của bạn, không gửi đi đâu.

Dữ liệu nguồn
Hợp đồnghop-dong.report…xlsx
Sự nghiệp (quyết định nhân sự)su-nghiep.general.report…xlsx
Quyết định thôi việcquyet-dinh-thoi-viec.report…xlsx
Kéo thả cả 3 file vào đây, hoặc bấm “Chọn file Excel” và chọn nhiều file cùng lúc. Hệ thống tự nhận diện file theo tiêu đề cột.
Chưa có dữ liệu Sau khi tải file, trang sẽ hiện 4 bảng: hợp đồng ký trong tháng (ngày ký, loại HĐ, thời hạn, lương), tăng lương (lương cũ → mới), bổ nhiệm và nghỉ việc.
Dữ liệu chấm công
1. Dữ liệu vân tayvân tay T…xlsx (Mã nhân sự, Ngày, Giờ vào, Giờ ra)
2. Đơn từ (Exported Timeoff)Exported.Timeoff…xls (Mã nhân sự, @tên nhóm, Ca đề xuất)
Hoặc: báo cáo đã xử lýFile Excel có sheet “Dữ liệu gốc” (cột Kết quả)
Kéo thả cùng lúc file vân tay và file đơn từ để trang tự tính, hoặc tải 1 file báo cáo đã có sheet “Dữ liệu gốc”. Trang tự nhận diện file theo tiêu đề cột.
Xuất Excel (tháng đang chọn, 1 sheet)
Chưa có dữ liệu chấm công Sau khi tải file, trang sẽ hiện tóm tắt theo tháng và theo khoa / bộ phận, bảng tổng hợp từng nhân sự, chi tiết các lượt bị tính và các lượt có đơn được miễn trừ.
